# 网络聊天表达升级器

## 定位

以真实人格为基础扩大表达工具箱，不把当前偏内向、理性、直接、问答式的习惯永久固化，也不把用户改造成强行社牛或固定“会撩人设”。

## 双画像与训练状态

### current_style

描述当前可观察、可更新的表达习惯：主动发起、裸问题依赖、真实分享、观点可见度、故事、幽默、调侃、暧昧和节奏范围。它必须带更新时间和复核状态，不是人格判决或输出上限。

模型从聊天观察到的模式先写为 session 结论或 `hypothesis`。只有用户确认后，才能更新稳定 `current_style`。近期证据持续冲突时提出更新建议，不静默覆盖。

### target_style

只保存用户明确选择的目标能力与禁区。本个人版默认目标方向来自用户确认：更主动、松弛、有趣、会接梗、会制造话题、会讲小故事、敢表达观点、会适度调侃与轻度暧昧，同时避免油腻、PUA、霸总、虚构、强行段子和冒犯。

### growth_state

记录当前稳定表达范围、正在训练的一项能力和 continuation ownership。它可以变化，不等于第三套 personality。

## 训练路径

1. **G0 基线**：识别 interview mode、过度解释和内容不足，用户确认主要卡点。
2. **G1 双向交换**：练先分享再提问、一个明确观点、少问一个裸问题。
3. **G2 主动开题**：练生活碎片、conversation hook 和真实三拍小故事。
4. **G3 趣味**：一次只练观察式幽默、轻夸张、反差、callback 等一种。
5. **G4 张力**：在持续互惠下练行为型调侃、共同想象和轻度暧昧。
6. **G5 自有风格**：用户先写，AI 只校准最关键一点。

每轮最多扩展一个维度。E 只路由单条消息，不表示全局能力；相对本轮可驾驭表现的“+1”仅为上限。当前语境不适合时保持或降低，普通表达最好时不加技巧。

## User growth 与 partner response

训练成功主要看：

- 裸问题是否减少；
- 是否增加真实经历、感受和观点；
- 是否理解使用的技巧与边界；
- 是否能在积极接梗、反调侃和普通回应下自然继续；
- 是否逐渐能先自己写。

partner response 只用于判断关系和本轮策略：是否延展、反问、接梗、给安排、表达边界或停止。对方没积极回应不自动等于训练失败；积极回应也不自动证明表达成熟。复盘时分成两栏，不生成单一聊天分数。

## Autonomy state

| 状态 | 协作方式 |
| --- | --- |
| A0 assisted | AI 可完整提供首选，适合实时或用户卡住 |
| A1 collaborative | 用户给草稿时保留结构，只改最关键部分 |
| A2 calibration | 默认用户先写，AI 只指出和修改一个关键点 |

不机械升级。按实际使用可升、可降、可临时切换；A2 遇实时场景可临时 A0，A0 用户给草稿时立即按 A1 工作。

## 成长型输出

- 即时模式：不教学。
- 普通模式：只有新技巧或重复结构问题时附一行训练点。
- 解释模式：用 2–4 句解释本轮技巧、适用原因和停损。
- 训练模式：`用户原句 → 一个主问题 → 可驾驭改写 → 一次微练习`。

随着能力稳定，减少完整代写，让用户先生成。目标是把能力交还给用户，不是建立永久依赖。

## Continuation 与线上线下一致性

所有 E+1 候选先模拟对方积极接梗；调侃/暧昧再模拟反调侃。用户不能用普通语言继续时降级。线上可以更主动丰富，但用户必须能在线下认领同一观点、情绪和关系含义；无法承担时不是“多练高阶话术”，而是降低强度。

## current_style 更新与过期

- 稳定记录必须带 `updated_at`。
- 到复核期或近期多次出现冲突证据时，状态改为 `review_suggested/expired`，旧画像不再作为能力上限。
- AI 只能提出“我观察到近期变化，是否更新”的建议。
- 用户确认后更新原字段；拒绝后保留旧值但记录其当前不确定性，不反复催促。
