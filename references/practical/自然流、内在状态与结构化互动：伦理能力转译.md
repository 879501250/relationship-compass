## 定位

这是 review/training 与 realization reference，用于用户明确想学习自然流、Blueprint 内在状态、Mystery 结构化互动或冷读式开场，或复盘“紧张、背稿、聊得散、阶段错位、不会看反馈”。涉及当前回复时，它只消费 Decision Layer 已选 Primary Action；诊断、任务与反馈表不得另选或替换 turn action。先用 [经典社交体系的机制、证据与风险边界](../knowledge/20-经典社交体系的机制、证据与风险边界.md) 判断可保留能力，再使用本文件落地。

不要重复已有主题：

- 需要更松弛的句子、现场取材或调情示例，读 [场景感、松弛感与社交校准](场景感、松弛感与社交校准：从接话到关系推进.md)。
- 需要一条即时回复和后续分支，读 [实战话术编排器](实战话术编排器：从一句回复到后续分支.md)。
- 涉及贬低、推拉、服从测试、煤气灯或性施压，读 [PUA、操控知识与伦理替代](../knowledge/05-PUA操控与伦理替代.md) 并切换安全替代。

## 一、先诊断一个主问题

| 现象 | 主要故障 | 训练／realization 修复 |
| --- | --- | --- |
| 很紧张，反复检查自己表现 | 内在状态 | 接受紧张，把训练目标缩小到一个可观察维度 |
| 背了话术却显得突兀 | 素材 | 从现场、对方原话和真实自己取材 |
| 聊得热但长期没现实推进 | 结构 | 形成“是否允许低压力现实验证”的 relationship-level hypothesis／Current Action candidate，交给 Decision Layer |
| 对方正在难过却被调情 | 结构错位 | 标记 serious constraint；当前候选若冲突则返回 Decision Layer |
| 句子本身可用但太长、太强或连发 | 表达 | 缩短、降一级强度、留回应空间 |
| 总想证明“我很懂你” | 冷读误用 | 改成观察—假设—校正 |
| 对方持续礼貌短答 | 反馈不足 | 形成降低投入／张力、归还 ownership 的上游 constraint，不在本表选 turn action |

一次只修最主要的故障，不把所有技巧堆进同一条消息。

## 二、内在状态：不等完美感觉

使用 60 秒重置：

1. **命名**：说出“我现在紧张／怕被拒绝”，不把它写成“我不会社交”。
2. **落地**：找三个当前可见或可听的细节，把注意力从自我监控移回现场。
3. **缩小**：只选一个训练目标，如减少自我监控、使用一个真实观察，或把已许可动作说清楚。
4. **许可**：允许句子不完美，也允许对方不感兴趣。
5. **行动**：在不造成压力的时机完成动作，然后读取反馈。

内在稳定不是“压住对方”。若对方拒绝，稳定的表现是接受信息、停止推进并保留自尊。

## 三、自然流生成器

### 观察—表达—可选接点

```text
具体观察 + 可选表达 + 仅在已授权时使用的接点
```

Pattern components are optional realization components gated by Primary Action, not sequential action escalation。`SHARE` 可使用“观察 + 表达”；`ASK` 才能加入真实问题；`PLAY` 才能加入共同玩笑；`INVITE` 才能加入活动或关系下一步。模板里出现第三段，不会自动授权 `ASK` 或 `INVITE`。

例（仅当 `Primary Action = ASK`）：“你刚才讲那家店时明显有点兴奋，我也被种草了。你最推荐哪一道？”

- 观察必须来自现场或对方真实说过的话。
- 表达提供用户自己的信息，避免查户口。
- 接点必须与已选 Primary Action 一致，并允许对方不接；没有对应权限时省略。

### 线程选择

从对方一句话里识别事实、情绪、价值、人物、场景和未来行动，只选最有情绪或最接近当前目标的一条。不要逐项追问。

对方说“最近换项目，天天加班，但周末终于能去爬山”。先接收已选动作，再取对应素材：

- 已选 `ACKNOWLEDGE / EMPATHIZE`：使用“天天加班”的疲惫。
- 已选 `ASK`：可询问为什么仍然想去爬山。
- 已选 `INVITE`：可使用周末安排写具体、低压力、可拒绝的共同活动。

### 双向自我披露

`Primary Action = ASK` 时，问题应有真实交流价值；若 supporting function 获准，可补一点相关的真实信息，但不能借“平衡提问”另建 `SHARE` 目标。披露深度受关系约束；不要用创伤、秘密或快速承诺制造速成亲密。

## 四、开放假设替代冷读

只在有可见依据时使用：

```text
事实：“你连续两次说怕打扰她。”
假设：“我猜你不只是不知道怎么发，也怕主动显得掉价。”
校正：“我猜得对吗？也可能只是你不想给她压力。”
```

猜错时说：“明白，是我刚才猜偏了。”然后用对方的纠正更新，不把错误重新包装成命中。

### 禁止版本

- 用“你外冷内热”“很少有人真正懂你”等高命中泛化句制造特殊感；
- 根据年龄、职业或性别给确定人格结论；
- 从社交媒体或共同朋友私下查到信息，再假装现场猜中；
- 重复对方刚透露的话，却声称自己早已看穿；
- 从聊天截图的一个表情或间隔断言对方的内心。

如果用户要“几句让她觉得我一眼看穿她”，先指出虚假洞察会损害信任，再给基于真实细节的具体好奇或赞美。

## 五、轻结构：不是升级漏斗

把互动看成五类可往返的 review 任务，不是 turn action 顺序，也不能按序自动升级：

1. **建立接触**：真实开场，确认现在是否方便。
2. **形成双向互动**：双方都在提供内容，而非一方表演或审问。
3. **了解适配**：表达具体欣赏，也了解价值、节奏和边界。
4. **现实验证**：观察是否已形成允许低压力邀约、联系方式或关系澄清的上游条件；当前轮是否执行仍由 Decision Layer 决定。
5. **确认与复盘**：把含糊、明确同意或拒绝形成 permission／hard constraint，不在本任务表内选择 `LEAVE_SPACE / CLOSE / WAIT` 等动作。

任务可回退、停留或结束。聊深不等于身体同意，接受联系方式不等于接受邀约，一次约会不等于关系承诺。

## 六、结构／素材／表达三层排错

收到聊天或复盘时按顺序问：

1. **结构**：这句话是否适合当前情绪、媒介和关系阶段？
2. **素材**：是否来自原话、现场或真实生活？是否符合用户口吻？
3. **表达**：长度、强度、时机和频率是否给了对方回应空间？

只输出一个主修复：

- 结构问题：标记候选与当前语境冲突并返回 Decision Layer，不在本文件内从邀约改为承接。
- 素材问题：删套路，换一个真实细节。
- 表达问题：短一半、降一级、停止连发。

## 七、反馈形成约束，不选择 turn action

| 反馈 | 观察 | 提供给 Decision Layer 的约束 |
| --- | --- | --- |
| 绿灯 | 主动延展、反问、玩笑、给具体时间或替代安排 | 可允许小幅、可逆表达，但不自动授权推进、邀约或提问 |
| 黄灯 | 相对基线持续礼貌短答、不反问、回避或含糊；或明确轻度不适 | 形成降低投入／张力与归还 ownership 的 constraint；由 Decision Layer 在 `DEESCALATE / LEAVE_SPACE / CLOSE / WAIT` 等动作间判断 |
| 红灯 | 明确拒绝、不适、僵住、躲避、要求停止 | 形成停止对应推进方向的 hard constraint；当前 turn action 仍由 Decision Layer 决定 |

反馈看趋势，不把单个表情、一次秒回、深夜长聊或礼貌配合当作确定喜欢。

## 八、输出模板

```text
主诊断：内在状态／结构／素材／表达／反馈中的一个
已选 Primary Action：来自 Decision Layer
可直接使用：一句符合用户口吻的话或一个线下动作
依据：一个可见事实 + 一个暂定判断
反馈约束：绿灯仅提供有限 permission；黄灯降低投入／张力；红灯形成 hard constraint，均不直接选择 turn action
复盘：是否真实、双向、可退出；下次只练哪一项
```

不要在普通输出里讲课程历史。用户明确要理论来源时，再说明哪些是教学框架、哪些有研究支持、哪些只是课程自述。
