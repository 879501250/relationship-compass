# 关系阶段与聊天节奏

## 三个分离维度

- **S 阶段（Stage）**：较长期的互动结构发展到哪里。
- **近期走势（Recent Trend）**：最近一段时间相对双方既有 baseline 的变化方向。
- **E 路由**：本轮表达趣味与暧昧强度，仅供内部选择。

三者不能互相替代。一次热聊不能直接升级关系阶段，一次慢回也不能直接判定降温；Stage 描述互动结构，不是对方内心感情强度或恋爱概率。

关系分析使用同一条链路：Observed Evidence → Reasonable Interpretation → Stage + Recent Trend → Evidence Strength／Conflict → Current Action。用户随后问“怎么回”时，才把 Current Action 交给 `自然回复生成器.md`；本文件不生成第二套回复逻辑。

## 职责边界

| 概念 | 只回答什么 |
| --- | --- |
| Relationship Stage | 较长期的关系结构／当前大致处于哪里 |
| Recent Trend | 相对同一对象 baseline 的近期变化方向 |
| Evidence Strength | 当前结论获得多少、什么质量的证据支持 |
| Feedback Color | 当前这一轮互动或行动建议的轻量门控，不是关系状态 |
| E | 当前一条消息允许使用的表达强度 |
| Memory confidence | 某个持久化 hypothesis 的内部置信元数据 |

这些概念相关但不能互相替代，也不能做固定映射。

## Stage：S0–S6

| 阶段 | 行为证据 | 优先任务 |
| --- | --- | --- |
| S0 陌生／弱连接 | 没有稳定互动 | 从真实场景建立一次连接 |
| S1 初步接触 | 零散聊天，互惠样本少 | 提供可回应素材，避免采访 |
| S2 双向了解／朋友互动 | 双方会发起、延展或分享，或已有稳定朋友互动 | 增加共同感，按边界寻找低压力见面机会 |
| S3 暧昧探索 | 持续特殊关注、单独邀约或双方可识别的暧昧互动，但未明确 | 小步验证，不把模糊信号当共识 |
| S4 稳定约会／澄清 | 持续见面和现实投入，需要讨论期待 | 协商节奏、排他与现实约束 |
| S5 已确认关系 | 双方有明确关系共识 | 关注兑现、修复和长期协商 |
| S6 结束／退出 | 恋爱或私人互动已明确结束，或用户决定停止 | 边界、恢复与必要事务沟通 |

Stage 主要依据较长期互动、双方明确关系陈述、现实互动与投入、边界、互惠和连续性。短期主动增加可以支持 warming trend，但不能独自把普通朋友升级为暧昧。明确“只想做朋友”会限制恋爱推进；若双方仍保持朋友互动，可同时表达“Stage 仍是朋友互动、Trend 可以升温、恋爱边界仍有效”，不必把所有友好互动都归为 S6。

用户明确说“我们已经正式在一起”时，关系状态可按现有 Memory policy 作为 confirmed relationship fact；模型根据互动推测“像在暧昧”仍只是 time-bounded hypothesis。Stage 输出使用自然名称，S 编号只在训练、调试或用户询问时显示。

## Recent Trend：相对 baseline 的变化

默认使用以下简单方向：

- **升温（warming）**：相对以往，主动、展开、互惠、连续性、现实投入或修复持续增加；
- **基本稳定（stable）**：互动形式与既有水平大体一致，即使绝对频率不高；
- **降温（cooling）**：相对以往，持续减少投入、只被动回答、回避或不兑现且不修复；
- **波动（fluctuating）**：时间维度上方向反复变化，例如先升温、随后退回、之后又恢复；
- **信息不足（insufficient）**：缺少此前 baseline、时间顺序、代表性样本或关键现实信息。

baseline 只与同一对象、相近现实条件下的既有互动比较，不套用通用回复速度。时间窗口按互动频率、关系长度和事件密度选择，不硬编码 3／7／14 天。优先使用自然事件窗口，例如考试结束后是否恢复互动、邀约是否落实、冲突后是否修复。

除明确拒绝、明确关系改变或重大现实事件外，Trend 通常需要多个观察点。一次晚回、短答、取消、热聊、表情或暧昧句都不能单独翻转 Trend；取消后是否解释、补约或反复回避，才更有区分度。没有 baseline 时可以描述“这轮有主动展开”，但不能把它自动写成“近期升温”。

Trend 的“波动”描述时间序列中的方向反复；Evidence Strength 的“存在冲突”描述当前证据支持不同解释。线上连续主动但现实邀约未落实时，可以是 `Recent Trend = 升温`、`Evidence Strength = 存在冲突`；这不自动等于 Trend 波动。反过来，多周升温、退回、再恢复可以判为波动，而证据本身未必冲突。

## Evidence Strength 与冲突

证据强度只用定性语言：

- **证据较充分**：有多条相对独立、重复或高价值证据，且有可比较 baseline；
- **有一定证据**：方向已有支持，但样本、现实投入或时间跨度仍有限；
- **证据有限**：主要依赖少量观察点或较多解释；
- **存在冲突**：支持与限制证据同时存在，不能压成单一乐观或悲观结论；
- **信息不足**：关键映射、顺序、baseline 或现实背景缺失。

判断时看证据数量、独立性、重复、高价值程度、推断依赖、冲突与 baseline；不把数量换算成权重或概率。明确关系陈述和边界优先于模糊聊天信号，现实见面、时间投入、兑现和替代安排通常高于表情、回复速度或一句暧昧话。

冲突证据要并列保留，例如“线上主动和展开增加，但连续现实邀约没有落实”。这可以支持“线上 warming、Evidence Strength 存在冲突”，而不是强行断言有戏或没戏，也不能把 Trend 自动改成波动。明确边界不会因聊天热络自动失效；可以同时说明互动仍积极，但当前 action 必须尊重边界。

## Current Action

分析不能停在 Stage／Trend。结合边界、互惠、可靠、可逆性、安全和机会成本，只选一个轻量当前动作，例如：

- 继续当前节奏；
- 稍微主动一点；
- 观察一两轮代表性互动；
- 暂时不再追问，把 continuation ownership 交还对方；
- 推进一次低压力现实见面；
- 先处理误会或修复；
- 尊重明确边界并停止关系升级。

缺证据时说明“目前能判断什么、不能判断什么、最关键缺什么”，只指出 1–2 个会改变动作的缺口，不自动启动长问卷。例如：“这轮能看出对方有主动展开；但缺少前几周通常是谁发起，所以暂时不能确定是否升温。”

普通分析默认简洁表达：

```text
我的判断：
阶段：……
近期走势：……
证据强度：……

关键依据：
- ……
- ……

现在更适合：……
```

不是每次都要展示完整模板。简单问题直接给短结论、1–3 条关键依据和动作；长记录默认仍只选 2–5 条关键证据，用户明确要求时才逐句分析。

## 内部 E1–E5

| 标签 | 含义 | 常见内容 |
| --- | --- | --- |
| E1 | 自然稳定 | 清楚回应、真实分享、普通观点 |
| E2 | 轻松活跃 | 生活碎片、画面、轻夸张、简单 hook |
| E3 | 幽默调侃 | callback、反差、假装严肃、行为型调侃 |
| E4 | 轻度暧昧 | 指向两人特殊感的欣赏、共同想象或调侃 |
| E5 | 明显暧昧 | 双方可识别的直接吸引和亲密张力 |

E 不是能力分数、Stage、Trend、Evidence Strength 或 Feedback Color。它只约束当前一条消息；即时模式隐藏，训练／调试或用户询问时才展示。

### 阶段上限

| 阶段 | 默认区间 | 绿灯上限 |
| --- | --- | --- |
| S0 | E1–E2 | E2 |
| S1 | E1–E2 | E3 |
| S2 | E2–E3 | E3 |
| S3 | E2–E4 | E4 |
| S4 | E2–E4 | E5，需持续互惠 |
| S5 | E1–E5，按语境 | E5 |
| S6 | E1 边界 | E1 |

E 只用于单条消息，不保存全局 stable E。相对本轮已证明可驾驭表现的“+1”只计算训练强度上限，不要求默认上调；Stage 较高也不意味着 E 必须高。实际强度取决于边界、Serious Mode、对方反馈、语境、本轮目标和 continuation ownership；普通表达最好时使用无技巧回复。

## 节奏与 Continuation ownership

观察：

- 谁发起话题、通话、见面和关系推进；
- 谁提供新信息、观点、感受、故事和 conversation hook；
- 对方不能参加时是否给替代方案；
- 双方是否能接梗、callback、兑现和修复；
- 用户是否连续裸问题、连发、补解释或单方救场；
- 当前形式相对双方现实 baseline 是否变化。

本文件只判断谁更适合承担下一步，不规定具体话术：

- 对方主动给新信息、感受、故事、反问或新线程：对方已承担一部分推进，用户可以沿一个点自然继续。
- 对方只回答、连续不延展，而用户近期已多次发起：把下一步交还对方；本轮回应、留空间或收线，不再机械追问。
- 双方都有内容：问题只是可选工具，分享、观点、回应和停顿同样能维持双向感。
- 当前线程自然完成：允许结束，不把沉默自动解释为失败，也不为续聊强造 hook。

是否“继续”看近期模式与当前一轮的互动贡献，不用固定提问次数或消息比例作硬阈值。具体生成交给 `自然回复生成器.md`。

## 反馈颜色

Feedback Color 只门控当前这一轮互动或行动：green 可继续，gray 暂不升级解释，yellow 降低强度或观察，red 停止某类推进。它不等于 Stage、Recent Trend 或 Evidence Strength；本轮 green／yellow 不能自动升降 Stage，也不能替代 Trend 输出。

| 颜色 | 含义 | 处理 |
| --- | --- | --- |
| green | 明确积极：主动、延展、接梗、兑现或给替代安排 | 可维持或小步上调；仍须通过 continuation ownership |
| gray | 中性或证据不足 | 保持自然，不因一次忙、短回或晚回自动降级；等待趋势证据 |
| yellow | 相对 baseline 持续低投入、重复不延展、回避同一推进方向或显示轻度不适 | 降低表达／投入、换普通话题或结束本轮，不换技巧追击 |
| red | 明确停止、边界、不欢迎、危险或操控 | 停止当前方向，优先边界与安全 |

单次忙、短回、晚回通常优先 gray。只有结合持续趋势、反复不兑现、无替代方案或明确不适，才升级为 yellow；不能把“尚不清楚”塞进 yellow。

## 升降规则

- green 可维持或上调 E 最多一级；上调仍须通过 continuation ownership，不代表 Stage 自动升级。
- gray 不自动升降，以普通、可逆表达继续观察。
- yellow 降一级、换普通话题或结束本轮，不换新技巧追击。
- red 停止当前方向。
- 悲伤、疾病、道歉、冲突、家庭压力、拒绝、边界、重要决定、公共群聊和权力差场景进入 serious 语气约束，通常降至 E1–E2；具体措辞交给自然回复生成器。
- 对象 A 接受 E4，不代表对象 B 接受；Stage、Trend、反馈与技巧记录按对象隔离。

## 训练与关系结果分开

`user_growth` 看自然与清晰表达、情绪理解、边界、真实内容、适度主动、互惠与节奏判断、社交舒适度、自然接续和独立生成。`partner_response` 看对方是否延展、接梗、给安排或表达边界。二者分别报告，不合成聊天分数，也不以是否“拿下”某个人评价成长。

# 投入预算与停止条件

## 目标

允许用户更主动、更有趣，同时防止表达训练变成单方维持关系。投入判断看行为、兑现和机会成本，不用固定回复时长或消息比例。

## 四个区域

| 区域 | 行为 | 默认动作 |
| --- | --- | --- |
| 互惠但节奏不同 | 对方会解释、延展、给替代时间或兑现 | 继续互动，协商节奏 |
| 证据不足 | 样本少、现实压力明确、事实与猜测混合 | 做一次能产生新信息的动作 |
| 持续失衡 | 长期只有用户发起/救场，反复失约且不修复 | 停止加码，交还主动并设停止条件 |
| 明确拒绝或危险 | 要求停止、拉黑、威胁、跟踪、勒索或暴力 | 停止推进，危险时走安全流程 |

## 投入检查

- 这条消息是在创造真实互动，还是只缓解我的焦虑？
- 我是否已经发出明确问题、邀约或澄清，却又想替对方补回应？
- 对方是否也提供新内容、主动发起、兑现或修复？
- 我是否给出超出当前阶段的金钱、时间、承诺或情绪劳动？
- 这段关系是否持续挤占睡眠、工作、朋友和其他选择？

表达成长属于用户能力，可以保留；对某个对象的单方供给不因“练习”而合理化。

## 一次动作与观察窗口

一次只完成一个主要目标。提出邀约后看是否给具体答复或替代安排；表达观点后看是否延展；使用玩笑后看是否接梗。观察窗口绑定自然事件，不机械倒计时。

没有明确拒绝且证据不足时，可以在出现新信息后主动一次。持续礼貌回应、不给新信息或两次代表性邀约都不提供替代安排时，优先降级投入。

## 降级不是操控

可停止单方策划、救场、随叫随到和超阶段付出，把资源还给自己的生活。自检：`如果对方没有追来，我仍认为这一步对我有利吗？` 若否，可能是在用撤退制造焦虑。

## 停止条件

- 再次无解释失约且不补救；
- 一次清楚澄清后仍长期回避；
- 再次越过已说明边界；
- 明确拒绝或要求停止；
- 关系持续造成明显功能损害且对方不愿协商；
- 出现安全风险。

停止后可不再私人联系；同事、同学、共同项目或共同抚养无法断联时，改为必要、简短、可留痕的事务沟通。

## 表达风险与关系风险

普通低风险聊天可以承担观察式幽默、真实观点或轻度 playful framing 的可逆风险；这不等于提高追逐频率、越过边界或忽略不互惠。表达可以成长，投入仍要由双方行为校准。
