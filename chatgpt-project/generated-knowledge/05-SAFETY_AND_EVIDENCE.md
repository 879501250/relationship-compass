# 微信截图解析协议

## 目标

把截图当作有限证据，稳定完成说话人识别、事实提取、互动结构判断和即时回复。不能从左右位置、头像性别、语气或单个表情推断身份和内心。

## 一、先锁定映射与顺序

1. 识别可见昵称、头像、气泡颜色、时间戳和引用关系。
2. 明确显示映射，例如：`用户＝右侧蓝色；对象A＝左侧白色`。
3. 只有左右没有账号信息时，请用户确认一次；后续同一批截图沿用，不因内容静默翻转。
4. 多图先按时间和上下文排序；重叠截图去重，缺页或跨日处标记断点。
5. OCR 不清的字写成 `[无法确认]`，关键内容看不清时请用户贴原文。

实时需求可先给基于最小安全假设的短回复，但必须说明假设。若说话人可能反转且会改变回复，不得猜。

## 二、建立证据账本

分四栏处理：

- **可见事实**：原文、谁发送、先后顺序、可见时间、是否回应、是否提出安排。
- **用户补充**：线下、语音、截图外背景和用户对语气的描述。
- **合理推测**：至少有一条行为依据，并保留替代解释。
- **关键未知**：会改变关系判断或回复目标的信息。

可说“她这三轮都回答了，但没有反问或增加新话题”；不能说“她只是在敷衍你”。可以判断“当前截图的投入偏被动”，不能把它升级为永久性格。

## 三、逐轮标注

每一轮最多标注这些可观察动作：

- `initiate`：开启新线程、主动联系、提出通话或见面；
- `answer`：只回答问题；
- `extend`：补充细节、情绪或故事；
- `return`：反问、把球抛回；
- `share`：提供自己的经历、观点或感受；
- `play`：接梗、反调侃、共同想象；
- `plan`：提出具体时间、地点、替代方案；
- `repair`：承认影响、解释并补救；
- `close`：自然收线、明确拒绝或要求停止。

不生成伪精确好感分。需要看趋势时使用自然时间窗或最近几段代表性互动，不把几小时不回设为万能阈值。

## 四、结构诊断

### interview mode

最近约三轮同时出现“用户主要问新问题、对方主要回答、用户缺少分享/观点/故事、没有问题就难继续”时，标记为 interview mode。下一轮不继续裸问题，优先：

1. 相关分享 + 可接钩子；
2. 一个真实观点；
3. 小故事或 callback；
4. 轻度调侃；
5. 自然换题或收线。

### 过度投入

观察连续追问、未回应时补解释、单方救场、重复邀约、超阶段情绪劳动和承诺。数量只能作为线索，最终看对方是否延展、兑现、修复和主动创造下一步。

### 反馈

- 绿灯：主动延展、反问、接梗、反调侃、给具体安排或替代时间。
- 黄灯：礼貌短答、疲惫、忙、忽略玩笑、连续不给新信息。
- 红灯：明确拒绝、不适、要求停止、威胁或越界。

单次表情和秒回不能单独定色；看趋势和语境。

## 五、输出

实时模式第一屏：

```text
可以直接发：
「一条成品」

节奏：现在发/稍后发；发完是否等待。
```

普通分析：

```text
结论：阶段 + 走势 + 本轮目标
首选回复：一条成品
依据：2–4 个截图事实
推测与替代解释：保持不确定
节奏：反馈分支、观察窗口、停止条件
```

普通模式不展示内部 E 数字。训练、调试或用户主动询问时才展示内部路由与技巧。

## 六、隐私与记忆

不保存原图、全文、账号、地址或私密影像。长期记忆只允许保存用户同意后的关键事件摘要、日期和证据编号；截图推断的意图、阶段和幽默接受度只能进入当前对象的 `hypothesis`，不能跨对象迁移。

# 证据分级与内容边界

## 一、为什么恋爱建议尤其容易失真

亲密关系研究常依赖自我报告，样本又多来自受教育程度较高的西方人群。关系是双人系统，同一句话在不同权力关系、文化、关系阶段和安全环境中可能产生完全不同的效果。此外，能预测“当前满意度”的变量，不一定能预测关系将来会变好或变坏。

2020 年一项汇总 43 个双人纵向数据集、11,196 对伴侣的研究发现，当前关系质量最稳健的关系层面预测因素包括：感知到的伴侣承诺、对伴侣的欣赏、性满意度、感知到的伴侣满意度和冲突；但关系质量随时间的变化仍然很难预测。这意味着应避免承诺“掌握某个指标就能预测婚姻结局”。

## 二、建议采用的证据等级

### A 级：优先使用

- 系统综述、元分析、预注册多研究项目。
- 大样本纵向或双人研究。
- 官方统计、现行法律、权威公共卫生指南。
- 适合表述：“综合证据较一致”“官方定义/现行制度为”。

### B 级：可以使用但要注明限制

- 设计良好的单项实验、自然观察或纵向研究。
- 有理论基础、在多个研究团队中出现的关系过程。
- 适合表述：“一项研究发现”“可能有帮助，仍需结合情境”。

### C 级：用于启发，不作定论

- 小样本、横断面、便利样本、单一文化研究。
- 定性访谈、案例研究、临床经验。
- 适合表述：“可作为提问框架”“不能据此判断因果”。

### D 级：流行框架

- MBTI 配对、星座、爱情语言、网络性别话术、“高价值/低价值”、未经验证的微表情读心等。
- 可以用来打开对话，但不能用于诊断、贴标签或重大决策。

## 三、四个常见推理错误

1. **相关当因果**：满意的人可能更会积极沟通，也可能因为满意才更愿意沟通；两条路径可以同时存在。
2. **平均当个人**：群体平均差异不能自动推断到某个男人、女人或某种人格类型。
3. **标签当解释**：“他回避型所以不沟通”只是改名，没有说明触发情境、具体行为与后果。
4. **技巧脱离权力**：要求被控制或被暴力的一方“更温柔表达”，可能增加危险或把责任推给受害者。

## 四、将抽象概念行为化

不要只问“他爱不爱我”，改问：

- 承诺：是否愿意讨论关系定义、未来安排，且言行长期一致？
- 回应性：我表达需要时，对方是否能理解、尊重并关心，而不是立刻否定或惩罚？
- 尊重：对方能否接受“不”、不同意见、独处和我的其他社会关系？
- 修复：冲突后是否有人重新接触、道歉、承担影响并落实改变？
- 公平：金钱、家务、照护与决策权是否经过协商，双方是否认为合理？

## 五、给未来内容系统的边界

- 不提供操纵、欺骗、跟踪、偷拍、灌醉、隔离、报复或绕过同意的方案。
- 不以性别、性取向、地域、收入、外貌或人格类型贬低某类人。
- 不诊断人格障碍、精神疾病或“依恋类型”；建议专业评估时说明理由。
- 不为暴力关系设计“共同沟通练习”；先做个人安全、法律和专业转介。
- 涉及未成年人、性健康、财产和婚姻法律时，必须提示地区与时效差异。

# PUA、操控知识与伦理替代

## 一、需要先拆分“PUA”的不同含义

中文语境里，PUA 可能指：

1. 基本社交训练：仪表、主动认识人、聊天、邀约、应对紧张。
2. 市场化“搭讪术”：背诵套路、追求转化率、把人当目标。
3. 情绪操控：贬低、推拉、孤立、制造嫉妒、服从性测试、煤气灯。
4. 胁迫与暴力：无视拒绝、性施压、跟踪、威胁、财务控制。

第一类能力可以用伦理方式学习；后三类应明确批判和阻止。学术研究常把 PUA 放在“男性圈/厌女网络”背景中讨论，指出其中将女性工具化、把亲密变成控制竞赛的倾向。

## 二、常见操控技术及机制

| 话术/行为 | 实际机制 | 风险 |
|---|---|---|
| Neg/贬低式赞美 | 先降低自尊，再让对方寻求认可 | 羞辱、形成权力差 |
| 忽冷忽热/推拉 | 间歇性强化，制造不确定和追逐 | 焦虑、依赖，不等于爱 |
| 服从性测试 | 从小要求逐步测试可控制程度 | 边界侵蚀 |
| 预选/制造嫉妒 | 用第三者抬高身价或威胁稀缺 | 不安全、竞争和报复 |
| 时间桥/假未来 | 承诺未来换取当下投入 | 欺骗、情感或性剥削 |
| 孤立 | 贬低朋友家人、占据全部时间 | 削弱求助网络 |
| 煤气灯 | 反复否认事实、扭曲记忆 | 自我怀疑、现实感受损 |
| 沉默惩罚 | 用断联迫使让步 | 控制；不同于约定暂停 |
| 性施压 | 用爱、分手、愧疚或酒精迫使性行为 | 同意失效、违法风险 |
| 财务控制 | 查账、限制工作、强迫转账、制造债务 | 经济虐待 |

这些方法可能在短期改变行为，但“能让人顺从”不等于“能建立自愿、稳定、互惠的关系”。WHO 将心理伤害、性胁迫和控制行为纳入亲密伴侣暴力范畴。

## 三、几个容易伪装成技巧的危险信念

- “拒绝只是测试诚意。”——拒绝就是当前不愿意，应停止推进。
- “女人/男人都慕强，所以要压住对方。”——把群体刻板印象当个人事实。
- “谁先认真谁就输了。”——把互惠关系变成权力博弈。
- “打压能筛掉高傲的人。”——真实作用是筛选出更能忍受不尊重的人。
- “对方被我激怒说明在乎。”——强烈反应不能证明爱或同意。
- “只要技术正确，就能拿下任何人。”——否定他人的主体性与退出权。

## 四、伦理替代：同样解决社交困难，不操控

| 原始需求 | 不健康做法 | 伦理替代 |
|---|---|---|
| 克服搭讪恐惧 | 背套路并把对方当练习对象 | 简短真实开场，允许拒绝，设定练习目标为“清楚表达” |
| 展示吸引力 | 吹嘘、假预选 | 呈现真实生活、兴趣、能力和待人方式 |
| 营造张力 | 贬低、嫉妒、故意消失 | 适度调情、幽默、眼神、明确兴趣，同时观察互惠 |
| 推进关系 | 服从测试、升级身体接触 | 提议下一步并询问意愿；每次升级都可撤回 |
| 保持边界 | 冷暴力、惩罚 | 直接说明底线、后果和自己的选择 |
| 避免过度投入 | 玩消失 | 保留正常生活节奏，诚实说明可用时间 |
| 面对拒绝 | 纠缠、辩论、报复 | 接受、停止推进、复盘适配与表达 |

## 五、识别自己是否正在被操控

连续问自己：

- 我是否越来越害怕说“不”或提出不同意见？
- 我是否为了换回对方的温柔，不断放弃原有边界？
- 对方是否制造问题，再把偶尔的善意当奖赏？
- 我是否被要求远离朋友家人，或为这段关系保密？
- 对方是否总能把其伤害行为解释成“是你太敏感”？
- 是否存在强迫性行为、威胁、跟踪、摔东西、堵门或控制金钱？

若后两类行为存在，优先阅读 17-中国法律安全与危机转介，不要把共同沟通当作首要方案。

## 六、教学红线

未来系统可以解释操控术的名称、识别方式与防御，但不能提供提高成功率的实施步骤。案例应以受影响者的安全为中心，不展示可直接复用的胁迫脚本。

涉及 Blueprint、冷读、Mystery 或自然流时，读取 20-经典社交体系的机制、证据与风险边界。冷读只能改为有可见依据、明确不确定并允许纠正的开放假设；结构化互动只能用于诊断当前任务，不能把人变成流程目标或把阶段当作升级权利。

# 同意、边界、性与亲密

## 一、同意是持续过程

同意应当是：

- 清楚：知道同意哪一种行为；同意亲吻不等于同意其他行为。
- 持续：过程中仍要观察和确认，不是一张永久通行证。
- 自由：没有威胁、操控、内疚施压、地位压迫或经济交换的强迫。
- 有能力：清醒并具备理解、选择和表达能力。
- 可撤回：任何时候都能改变主意，包括已经开始之后。

沉默、僵住、过去同意、恋爱/婚姻关系、穿着、进入房间或接受礼物都不能自动代表同意。

## 二、把同意做成自然对话

- “我想吻你，可以吗？”
- “这样舒服吗？要更慢、停下还是继续？”
- “你看起来有点犹豫，我们先停一下。”
- “你不用照顾我的失望；不想继续完全可以。”

“热情同意”是有用文化理想，但实际判断仍应注意清楚、自由、能力和持续性。有人表达方式安静或受文化、残障影响，不能只用兴奋程度作为唯一标准。

## 三、边界与控制的区别

边界描述“我会参与什么、我如何保护自己”：

> “如果争吵中出现辱骂，我会结束当次对话，等双方平静再谈。”

控制描述“你必须怎样，否则我惩罚你”：

> “你不许有异性朋友，否则我就查你手机。”

合理边界也要考虑比例、透明度和双方权利。把嫉妒包装成边界，并不能让控制合理化。

## 四、性沟通的基本议题

在发生性行为前后，双方应能讨论：

- 想要、不要和仍不确定的行为。
- 避孕责任、方法、失败预案与生育意愿。
- 性传播感染检测、窗口期和保护措施。
- 疼痛、不适、药物、疾病和身体差异。
- 隐私：影像是否拍摄、保存、转发；默认不拍、不传播。
- 性排他性的定义：线下性行为、色情互动、约会 App、网络暧昧是否算越界。

医学与避孕建议要转介正规医疗机构，不能凭关系技巧替代检查。

## 五、性欲差异

性欲差异很常见，不应简单归结为不爱或出轨。可讨论：

- 压力、睡眠、疼痛、药物、激素、产后变化和心理健康。
- 自发性欲与回应性欲的差异。
- 亲密是否总被等同于性交，是否存在其他双方愿意的表达。
- 拒绝是否被安全接纳；提出性需求是否会被羞辱。

目标不是让低欲方服从高欲方，也不是让高欲方永远沉默，而是在同意前提下理解、协商；持续困扰可寻求性医学或合格治疗师。

## 六、研究能支持什么

大型关系项目把性满意度列为当前关系质量的稳健预测因素之一；性沟通与性满意、关系满意之间也有元分析关联。但这不表示更频繁或更“技巧化”的性必然更好，满意度、自由、安全和双方需求比单一频率更关键。

WHO 对性健康的定义强调积极、尊重、愉悦与安全，以及免于胁迫、歧视和暴力。

## 七、高风险信号

- 用分手、出轨、自伤、曝光隐私或经济后果逼迫性行为。
- 趁醉酒、睡眠、意识不清推进。
- 偷偷摘除或破坏安全套，隐瞒重大性健康信息。
- 未经同意拍摄、保存、展示或传播私密影像。
- 对拒绝发怒、羞辱、纠缠或“磨到同意”。

这些不是沟通风格差异，应停止行为并考虑医疗、法律和安全支持。

# 中国法律、安全与危机转介

更新日期：2026-07-20。法律会变化，本文件只作基础识读，不构成个案法律意见。

## 一、先判断是否属于普通关系问题

以下行为应升级为安全问题：

- 殴打、掐脖、限制自由、堵门、抢手机、摔砸或以武器威胁。
- 强迫性行为、趁意识不清实施性行为、私密影像威胁。
- 持续跟踪、骚扰、定位、冒充登录或到单位/住处堵截。
- 隔离朋友家人、限制工作、没收收入、强迫债务。
- 以伤害自己、对方、孩子、宠物或家人为手段迫使复合/服从。
- 违反分手边界并升级接触频率和威胁。

不要用“他只是太爱”“她依恋焦虑”“双方都有错”淡化危险。

## 二、中国反家暴法律基础

《反家庭暴力法》规定，家庭暴力包括家庭成员之间以殴打、捆绑、残害、限制人身自由以及经常性谩骂、恐吓等方式实施的身体、精神等侵害；家庭成员以外共同生活的人之间实施的暴力行为参照适用。

当事人遭受家庭暴力或面临现实危险，可向人民法院申请人身安全保护令。保护令可包括：

- 禁止实施家庭暴力。
- 禁止骚扰、跟踪、接触申请人及相关近亲属。
- 责令迁出申请人住所。
- 其他保护人身安全措施。

法院原则上应在受理后 72 小时内作出裁定；紧急情况 24 小时内。具体管辖、材料和执行应咨询当地法院或专业法律服务。

## 三、证据保存

在不增加危险的前提下保存：

- 报警和出警记录、告诫书、询问笔录。
- 医疗记录、伤情照片、诊断和费用单据。
- 威胁、道歉、控制或跟踪的聊天、录音、邮件。
- 门禁、监控、定位和目击者信息。
- 财务转移、强迫借贷、账号控制记录。
- 居委会、村委会、妇联、学校或单位介入记录。

备份到对方无法访问的设备或可信联系人处。不要为了取证故意激怒对方或返回危险现场。

最高法等部门 2022 年意见强调家暴的私密性和突发性，并要求相关部门协助搜集、固定证据。2025 年最高法典型案例也确认，持刀自残威胁造成恐惧等情形可能构成精神暴力；个案结论仍由法院依法判断。

## 四、即时安全计划

- 发生现实危险时优先离开，联系 110；有医疗急症联系 120。
- 告知至少一名可信的人，约定求救暗号。
- 准备身份证件、现金/银行卡、药物、钥匙、充电设备和必要衣物。
- 了解附近派出所、医院、法院诉讼服务和可用庇护资源。
- 检查共享定位、云相册、家庭账号、智能家居和设备登录。
- 如带孩子或宠物，提前考虑安全转移；不要把计划透露给可能转告加害者的人。

各地妇联、法律援助、庇护与热线服务可用性不同，应通过当地政府/妇联/司法行政机关官方渠道核实。全国性号码与服务范围也可能调整。

## 五、自伤或伤人威胁

把威胁当真，但不要独自承担“必须继续恋爱才能救他/她”的责任：

- 有立即危险、具体计划、工具或失联时，联系 110/120，并通知其可信家人或当地可介入人员。
- 不承诺保密，不单独前往可能危险地点。
- 清楚表达：“我会联系能保证安全的人，但不会用继续关系交换你不伤害自己。”
- 保留威胁记录；如果威胁被用于控制，也纳入安全评估。

## 六、婚姻财产与离婚基础提醒

民法典婚姻家庭编涉及结婚、夫妻关系、财产、债务、离婚、子女抚养和救济。几个常见误区：

- 婚姻内所有债务并非自动共同债务；共同意思表示、家庭日常生活需要及超出范围债务的认定有具体规则。
- 夫妻可对婚前及婚姻关系存续期间财产作书面约定。
- 协议离婚冷静期不等于诉讼离婚冷静期。
- 家务劳动、照护贡献、房产出资、赠与、直播打赏等争议需要结合现行法律与司法解释判断。

重大资产、未成年人、跨境身份、公司股权或家暴情形应尽早咨询执业律师，不要依赖社交平台模板。

## 七、婚恋诈骗

对网恋投资、博彩、虚拟币、陌生 App、代收转账、紧急借款和裸聊勒索保持高警惕。发现被骗：停止继续付款、保存聊天和转账信息、联系银行/支付平台并尽快报警。不要相信“交解冻费就能提现”。
