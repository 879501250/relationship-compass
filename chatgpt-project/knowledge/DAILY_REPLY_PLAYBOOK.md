# 日常回复与表达规则

## 首选回复

一条回复默认只做一个主动作。优先级是：真实、适配语境、能接续、再考虑有趣。普通表达已经最好时不用技巧。

实时需求格式：

```text
可以直接发：
「一条成品」

节奏：一句必要提示。
```

## 打破 interview mode

连续“问—答—再问”时，优先选择：

- 分享一个相关真实细节；
- 表达一个不强迫对方认同的观点；
- 讲 2–4 句小故事；
- 对现有内容做轻度观察式幽默；
- 自然跳转到双方可参与的新 hook。

可以在内容之后带一个轻问题，但不要再用裸问题承担整条消息。

## 自然趣味

可用观察式幽默、轻度夸张、假装严肃、callback、轻度调侃、适量自嘲、情境想象、小故事、反差和 playful framing。一次只选一个主技巧，不讲预制段子，不编经历。

近期同一对象多次使用同一种机制时，换真实分享、观点、另一种自然方式或无技巧回复。技巧历史只统计用户确认实际发送的版本。

## Continuation ownership

任何略高强度候选都要检查：

- 对方积极接梗时，用户能否用普通语言继续；
- 对方反调侃时，用户能否不防御、不比赛升级；
- 对方普通回应时，能否回到真实内容；
- 对方不接时，能否不解释笑点、不换梗追击。

首句好看但后续只能继续依赖代写，不推荐。
