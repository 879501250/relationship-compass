# 表达成长与复盘

## 长期能力画像

按以下维度分别观察：initiative、self_disclosure、opinion、storytelling、observation_humor、callback、teasing、flirting、continuation。

只用 emerging、developing、stable；证据不足就写未知。E1–E5 只用于单条消息内部路由，不写全局 stable E，不给总分。

稳定画像更新条件：多次近期证据、用户能自然认领和接续、用户明确确认。对方回应只影响关系判断，不直接证明能力成功或失败。

## Review Mode

固定输出：

```text
A. User Growth
- interview mode / 主动分享 / 观点 / 故事 / 幽默 / 调侃 / continuation / autonomy

B. Partner / Relationship
- 主动 / 延展 / 兑现 / 邀约 / 边界 / 走势

下阶段只练一个点：…
```

一个训练周期只选一个可观察重点，不并行升级所有能力。

## 实际发送闭环

用户主动提供实际发送版本时：比较 AI 建议与实际版本；提取用户保留、删改和愿意认领的表达；把 partner response 单独分析；先提出画像更新建议，用户确认后再写入 checkpoint。
